UNDANGAN DIGITAL PERSONAL — GITHUB PAGES

Yang diubah:
- Nama tamu tampil di halaman pembuka, sebelum tombol "Buka Undangan".
- Nama dibaca dari parameter URL ?to=...
- File JavaScript bernama script.js (huruf kecil) agar cocok dengan index.html dan GitHub Pages yang case-sensitive.

CONTOH LINK
https://USERNAME.github.io/NAMA-REPO/?to=Bapak%20Andi%20dan%20Keluarga

CARA DEPLOY GRATIS
1. Ekstrak folder icul2 dari ZIP ini.
2. Buat repository GitHub baru, misalnya undangan-viona-danuarta.
3. Upload isi folder icul2 ke root repository (index.html harus terlihat langsung di halaman utama repository, bukan berada dalam subfolder icul2).
4. Buka Settings > Pages.
5. Pada Build and deployment, pilih Deploy from a branch, pilih branch main dan folder /(root), lalu Save.
6. Tunggu hingga GitHub Pages menampilkan URL website.
7. Gunakan URL itu sebagai dasar setiap link tamu, lalu tambahkan ?to=Nama%20Tamu.

CATATAN
- Link personal belum dibuat karena file daftar nama tamu belum diterima di percakapan ini.
- Setelah URL GitHub Pages tersedia dan daftar nama diunggah (Excel/CSV/teks), daftar link personal bisa dibuatkan dalam CSV/Excel.
- Jangan mengganti nama script.js menjadi Script.js kecuali referensi di index.html juga diubah.
